# FYS-STK4155

Welcome to our repository for Project 2 for FYS-STK3155 / FYS-STK4155!

Here, we present a thorough analysis of Runge's function. We investigate various Linear Regression methods, Gradient Descent algorithms, both regular and stochastic, and optimiser algorithms. We look at optimal polynomial degree, penalty parameter $\lambda$, and learning rate $\gamma$, amongst other ML concepts. We hope you enjoy!

## Running the code

The code has to be run from the directory Project2/code, so from the root directory run `cd Project2/code`. Then run either of the three python files `main_regression.py`, `main_classification.py` or `meta_analysis.py` with `python insert_name.py`.  

To use `main_regression.py`:
- In line 15, choose which part you want to select, either "part_b", "part_c", "part_d", "part_f", "plot_f" or "baseline". 

To use `main_classification.py`:
- Before the if-loops the variables `select_architecture`, `select_learning_rate_norm`, `select_learning_rate_norm_with_test_data`, `select_learning_rate`, `select_final_learning_rate`, `select_accuracy_analysis`, `select_best_model`, `select_confusion_matrix`and `select_sklearn_model` can be changed between True (on) and False (off). 

`meta_analysis.py` can be run without any changes to the file.
