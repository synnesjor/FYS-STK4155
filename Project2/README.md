Welcome to our repository for Project 2 for FYS-STK3155 / FYS-STK4155!

Here, we present an examination of neural networks, with a focus on predicting the One Dimensional Runge function and classifying the MNSIT digits dataset. We delve into optimisation of neural network architectures, optimiser methods, learning rates, regularisation (l1 and l2 norms) and activation functions.

## Running the code

The code has to be run from the directory Project2/code, so from the root directory run the command `cd Project2/code`. Then run either of the three python files `main_regression.py`, `main_classification.py` or `meta_analysis.py` with the command `python insert_name.py`.  

### Regression

To use `main_regression.py`:
- In line 15, choose which part you want to select, either "part_b", "part_c", "part_d", "part_f", "plot_f" or "baseline".

#### part_b

This part of the code does the initial analysis, where we calculate the MSE values for a range of learning rates. Standard architecture is 1 hidden layer of 50 nodes, or 2 hidden layers of 100 nodes, but these numbers are flexible. Standard activation function for hidden layers are sigmoid and the output layer has no activation function, but this may be changed also. When the optimal learning rate has been identified, we train our neural network, and compare it to the OLS results from Project1.

#### part_c

This part investigates the number of hidden layers and nodes; our goal is to identify the optimal combination of these hyperparameters. We also test various activation functions and optimisers for the gradient descent. Running this full part TAKES TIME! That is why we run this and save the data and then plot, we do not plot in the run. The plotting script can be found in the plotting_scripts folder. 

#### part_d

This part investigates Ridge and Lasso regularisation norms (l1 and l2). The goal here is to analyse whether the implementation of a penalty parameter would result in better results for our model.

`exercise_d.py` is run via `main_regression.py` by selecting "part_d", however it can also be run by itself in the `code/` directory.

#### part_f

In this part we perform a k-fold cross-validation for our regression problem, investigating the learning rate and the penalty parameter. Running this full part TAKES TIME! That is why we run this and save the data and then plot, we do not plot in the run. The plotting script can be found in the plotting_scripts folder. 

#### Plotting Scripts

For the scripts in `plotting_scripts/`, run either `heat_map_plot_layers_and_nodes.py` or `heat_map_plots_cross_validation.py` with the command `python plotting_scripts/insert_name.py` in the directory `code/`. These are connected to the regression case and require data files saved by running the other scripts in `main_regression.py`.

### Classification

To use `main_classification.py`:
- Before the if-block the variables `select_architecture`, `select_learning_rate_norm`, `select_learning_rate_norm_with_test_data`, `select_learning_rate`, `select_final_learning_rate`, `select_accuracy_analysis`, `select_best_model`, `select_confusion_matrix` and `select_sklearn_model` can be changed between True (on) and False (off). The names here are self-explanatory. Certain if-blocks require other if-blocks to be run first (such as `select_best_model` before `select_confusion_matrix`).
